# 🎯 Number Guessing Game

A simple and interactive Number Guessing Game built using **HTML, CSS, and JavaScript**.

## 🎮 Features

- Generates a random number between 1 and 100
- Allows the user to enter a guess
- Shows whether the guess is too high or too low
- Counts the number of attempts
- Displays a winning message when the correct number is guessed
- Includes a restart button
- Simple and responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Play

1. Enter a number between **1 and 100**.
2. Click the **Guess** button.
3. Follow the hint:
   - 📈 Too High
   - 📉 Too Low
4. Continue guessing until you find the correct number.
5. Click **Restart** to start a new game.
